# travel-budget-optimizer

Progetto Java 25 gestito con Maven per l'ottimizzazione del budget di viaggio.
Il progetto contiene una struttura iniziale; la logica di ottimizzazione non
e' ancora implementata.

## Requisiti

- JDK 25 o successivo
- Apache Maven 3.8.7 o successivo

## Compilazione e test

```sh
mvn clean verify
```

Il codice viene compilato per Java 25.

## Avvio

```sh
java -jar target/travel-budget-optimizer-1.0.0-SNAPSHOT.jar
```
